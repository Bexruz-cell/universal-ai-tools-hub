# 🚀 Инструкция: Подключение SuperActions к ChatGPT

Данная инструкция пошагово описывает, как подключить созданный бэкенд-сервер к ChatGPT через **Custom GPT Actions**.

---

## Шаг 1. Локальный запуск сервера

Откройте терминал в папке проекта и выполните команду:

```bash
uvicorn server.main:app --host 0.0.0.0 --port 8000 --reload
```

* Сервер запустится по адресу: `http://localhost:8000`
* Интерактивная документация Swagger: `http://localhost:8000/docs`
* OpenAPI схема: `http://localhost:8000/openapi.json`

---

## Шаг 2. Вывод сервера в интернет (Публичный URL)

Поскольку сервер запущен на вашем компьютере, ChatGPT нужен доступ через публичный интернет. Для этого используем бесплатный безопасный туннель:

### Вариант А: Cloudflare Tunnel (Бесплатно, без регистрации)
Скачайте `cloudflared` или выполните:
```bash
cloudflared tunnel --url http://localhost:8000
```
В терминале появится публичная ссылка вида:
`https://random-words.trycloudflare.com`

### Вариант Б: Ngrok
```bash
ngrok http 8000
```
Ссылка: `https://your-id.ngrok-free.app`

---

## Шаг 3. Настройка Custom GPT в интерфейсе ChatGPT

1. Откройте **ChatGPT** -> Нажмите на свой профиль -> **My GPTs** (Мои GPT) -> **Create a GPT** (Создать GPT).
2. Перейдите во вкладку **Configure** (Настройка):
   - **Name:** `SuperActions Hub Assistant`
   - **Description:** `Универсальный ассистент с доступом к веб-скрейпингу, конвертации валют и каталогу AI-инструментов.`
3. В поле **Instructions** (Инструкции) вставьте:
   ```text
   Ты — интеллектуальный ассистент SuperActions Hub.
   У тебя есть доступ к внешним инструментам через Actions:
   1. Чтение и извлечение чистого текста из любых веб-страниц (/api/v1/web/scrape).
   2. Конвертация мировых валют и фиата (/api/v1/finance/convert).
   3. Поиск по каталогу ТОП-50 репозиториев для ChatGPT (/api/v1/catalog).

   Когда пользователь просит проанализировать ссылку или проверить курс валют,
   всегда используй соответствующие Actions и давай структурированный, точный ответ.
   ```
4. Прокрутите вниз и нажмите **Create new action** (Создать действие).
5. В поле **Schema** (Схема) вставьте содержимое файла `server/openapi.yaml` (или `server/openapi.json`).
6. В строке `servers` в схеме замените `http://localhost:8000` на ваш публичный URL от Cloudflare/Ngrok:
   ```yaml
   servers:
     - url: https://your-tunnel-url.trycloudflare.com
   ```
7. Нажмите **Save** (Сохранить) в правом верхнем углу.
